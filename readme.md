What is Machine Learning?
To teach computers how to think like humans the field of artificial intellingence has grown immensely, with one domain growing at an incredible rate.
ML is basically trying to understand patterns in data to predict outcomes that aid in decision making.

AI vs ML vs DL
AI is the broader field encompassing all efforts to teach coputers to think, ML is a sub-domain using algorithms attempted at drawing patterns from data to make probabilistic predictions, DL is a sub-domain of ML where we neural netwroks are used to derive information from large, unstructured data.
